# [Security Policy](#security-policy)

This software implements other software, it's not very likely that this software introduces new vulnerabilities.

## [Supported Versions](#supported-versions)

CI tests this role with [ansible](https://pypi.org/project/ansible/) 15.0.0. This version of ansible is supported:

| Version | Supported          |
| ------- | ------------------ |
| 15      | :white_check_mark: |
